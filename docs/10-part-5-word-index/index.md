# ภาค ๕ สารบัญค้นคำ {.ptb-h-block}

<PtbParagraph>ในหนังสือพระไตรปิฎกฉบับสำหรับประชาชนฉบับพิมพ์ สารบัญค้นคำรวบรวมคำที่น่าสนใจพร้อมเลขหน้าที่ปรากฏ สำหรับเว็บไซต์นี้ได้ปรับรูปแบบใหม่โดยจำแนกคำศัพท์ออกเป็น ๑๐ หมวดหมู่ พร้อมลิงก์เชื่อมไปยังเนื้อหาที่เกี่ยวข้องโดยตรง เพื่อให้ผู้ศึกษาสามารถเข้าถึงข้อมูลได้สะดวกยิ่งขึ้น</PtbParagraph>
