# บุคคลในประวัติศาสตร์ {.ptb-h-block}

<PtbParagraph>รวบรวมบุคคลสำคัญที่มีบทบาทในการสังคายนา การจัดทำพระไตรปิฎก การเผยแผ่พระพุทธศาสนา และผู้อุปถัมภ์สำคัญ ตามที่ปรากฏในพระไตรปิฎกฉบับสำหรับประชาชน</PtbParagraph>
