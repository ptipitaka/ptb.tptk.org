<PtbParagraph>คัมภีร์ที่อ้างคือพระไตรปิฎกบาลี ฉบับสยามรัฐ ฉบับพิมพ์ครั้งที่ ๗ พุทธศักราช ๒๕๕๖ เลขท้ายอักษรย่อ คือ เล่ม/ข้อ/หน้า เช่น <strong>องฺ. ติก. ๒๐/๔๙๙/๑๘๖</strong> หมายถึง คัมภีร์อังคุตตรนิกาย ติกนิบาต เล่ม ๒๐ ข้อ ๔๙๙ หน้า ๑๘๖</PtbParagraph>

<PtbParagraph>ส่วนคัมภีร์อ้างอิงพระไตรปิฎกฉบับภาษาไทยคือพระไตรปิฎกสยามรัฐภาษาไทย พิมพ์ครั้งที่ ๑/๒๕๕๙</PtbParagraph>
